# Predição de Hs com PCA e LASSO

Este trabalho utiliza dados do ERA5 para prever a altura significativa
de ondas (Hs) com 12 e 24 horas de antecedência.

Foram comparadas três abordagens:

- Persistência;
- PCA associado à regressão linear;
- Regressão LASSO.

A base possui dados de 1985 a 1994, com registros a cada seis horas.

## Arquivos

- `Atividade_1_BD_Ondas_e_Ventos_06out.ipynb`: código completo e resultados;
- `saida_completa_ecmwf_itaguai_1985-1994.xlsx`: base utilizada na análise;
- `Tarefa1_Predicao_de_Hs_Roberta&Rafael.pdf`: relatório do trabalho.
